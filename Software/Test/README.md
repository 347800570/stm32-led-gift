# 基础实验导航

这些工程保留分模块验证过程；最终功能以Official Version中的两套固件为准。实验工程未全部在本次发行中重新上板验证。

| 顺序 | 目录 | 目标和观察方法 |
| --- | --- | --- |
| 1 | 1_Flashing Code | 验证供电、复位和SWD下载链路 |
| 2 | 2_Uart Host | UART接收并原样回显，串口参数以工程配置为准 |
| 3 | 3_Light Led | 验证WS2812B数据时序和输出接线 |
| 4 | 4_Temperature Sensor | DS18B20读取、CRC和串口温度输出 |
| 5 | 5_Micro | ADC采样和串口观察麦克风信号，需模拟电路正常 |
| 6 | 6_IR | NEC学习与查表识别两个工程，输出按键码/名称 |
| 7 | USB DFU | 不需要单独应用工程，操作见根目录docs/quick-start.md |
| 8 | 8_Rainbow Gradient | 单路流动彩虹、led模块化驱动 |
| 9 | 9_Light Led 2 | 修改灯珠数量，测试连接完整性 |

各目录打开MDK-ARM下的uvprojx；驱动路径已改为仓库内ThirdParty。不要把正式版本的灯珠数、引脚或串口参数直接假设为每个实验的配置。
早期阻塞式串口回显只适合基础验证，大量连续输入可能发生接收溢出；正式应用使用独立日志发送机制。
个人原始实验日志、编译日志和调试器会话未收录。
