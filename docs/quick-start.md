# 接线与使用

## 硬件资源

| 功能 | MCU引脚/资源 | 连接说明 |
| --- | --- | --- |
| 灯带 | PB0 / TIM3_CH3 / DMA1通道2 | 经SN74LVC2T45电平转换至LED1_DATA，再接DIN |
| 第二路灯带 | PB1 | 配置保留，本版本不用 |
| 红外 | PA3 / 双边沿EXTI | DYWH-IRM-3638T输出，TIM14测量脉宽 |
| 温度 | PA2 / 开漏GPIO | DS18B20，外部上拉、独立VDD供电 |
| 麦克风 | PA0 / ADC_IN0 | ZTS6216经模拟放大和偏置后输入，TIM1触发8kHz采样 |
| 日志串口 | PB6 TX、PB7 RX | 3.3V串口，115200、8N1，共地 |
| SWD | PA13 SWDIO、PA14 SWCLK | 可额外接NRST；按下载器说明处理参考电压引脚 |
| 电源 | Type-C 5V，板上转3.3V | 灯带使用5V，MCU使用3.3V |

正式固件没有启用实体按键。麦克风ADC输入须保持在允许范围内，不要将5V数字电平接入ADC。
具体元件和接口编号以原理图为准；本表不是PCB端子的物理脚序。

## SWD下载

BOOT0置低；板子可靠供电后连接SWD和GND。使用STM32CubeProgrammer选择ST-LINK，连接、打开HEX、下载并校验，然后复位。
已供电主板不要再接下载器的3.3V电源输出；若端子是VTref电压检测输入，则按下载器说明连接。

## USB DFU下载

1. 使用支持数据的USB线，将BOOT0跳帽接到板上3.3V电源网络。
2. 上电或按复位，使MCU从系统存储器启动。BOOT0不是要求断电时仍有电压。
3. 在STM32CubeProgrammer中选择USB，刷新并连接DFU设备；Windows若未识别，应安装CubeProgrammer附带的DFU驱动。
4. 打开对应HEX并执行下载/校验。HEX含地址，不要按BIN方式重新指定偏移。
5. 将BOOT0恢复到GND，再复位，运行应用程序。

作者调试时曾遇到USB信号悬空及特定USB连接路径兼容性问题，换用拓展坞后连接成功；拓展坞不是本项目的必需硬件。

## 遥控与调试

协议为NEC，地址00 FF。POWER=0x45；1～9依次为0C、18、5E、08、1C、5A、42、52、4A；+=40、-=19、LEFT=07、RIGHT=09。
只有调节键支持长按重复。灵敏度共5档，数字越大越敏感。

9号鼓点门槛目前各档为背景能量×3.0/2.5/2.0/1.5/1.0，再加144/100/64/36/16；滤波、再允许触发和150ms防重复条件还需同时满足。
诊断中的PEAK和TH来自同一个采样块；HIT是窗口触发数，BELOW/RISE/ARM/LOCK是采样块分类数，不是漏掉的鼓点数。

灯不亮先检查DIN方向、5V与共地；有日志无遥控响应时先核对地址和键码；声控无反应时观察BIAS、AMP、CLIP和ERR，再用示波器检查模拟输出。
